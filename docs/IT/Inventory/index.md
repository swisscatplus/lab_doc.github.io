Swiss CAT+ has a global inventory system. 

{: .important }
> We stick label onto each bottle and record it inside the system. The system only knows barcodes of the labels. It doesn't know in advance the product.

The system is available here:

Available here : <span class="fs-2">[Inventory](http://swisscatsrv5:8123/fr/Main/Login?targetAction=Detail&targetController=Location&targetId=8){: .btn .btn-green }</span>

We can have access to location, products, id, recorded date and a 3D representation of the different plates with the products on it.
