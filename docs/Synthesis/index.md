The synthesis sections gathers multiple glove boxes. 
Some of them are Chemspeed glove boxes. They are controlled through the Autosuite software.

Then to pilot both glove boxes, we can use the Arksuite software.

Other glove boxes are handled by the STORMS project. 

We also have a pipetting system developed in house.

Each control section is defined in the IT section.
